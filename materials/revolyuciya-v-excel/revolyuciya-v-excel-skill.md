# Революция в Excel: ИИ внутри таблицы — материал для вашего ИИ

> Это конспект вебинара сообщества **хакку.ии | бИИзнес** в формате, готовом отдать вашему ИИ-ассистенту. Приложите файл в чат и попросите: «Разбери это и помоги мне применить ИИ к моим таблицам» или «Собери из этого навык по работе с данными в Excel».

## Что это и когда применять

ИИ переехал внутрь таблицы: в Excel появляется боковая панель (Claude for Excel), которая видит вашу книгу целиком, читает и меняет данные, пишет формулы, строит дашборды — а вы ставите задачу словами.

Применяйте, когда время уходит не на аналитику, а на подготовку к ней: чистка грязных данных, ручная разметка категорий, формулы наугад, еженедельная пересборка отчётов.

**Правило 80/20:** формульная, «умная» работа — это ~20% времени. Остальные 80% — перекручивание данных (найти таблицы, свести листы, почистить мусор). ИИ забирает себе именно эти 80%.

## Главная модель: связка двух ролей

ИИ в таблице — это не одна кнопка, а **две роли в паре**:

1. **Аналитик над таблицей** — ИИ внутри Excel. Видит только открытую книгу: чистит, считает, строит графики, пишет формулы. Силён, но заперт в одной книге.
2. **Агент-добытчик** — отдельная сессия ИИ (напр. Claude Code) с доступом к источникам: CRM, база знаний, Google Drive/Sheets, 1С. Достаёт нужный срез данных, которого нет в книге.

Связка даёт то, чего нет у каждой роли отдельно: аналитик считает не «вообще», а по вашему реальному бизнесу. **Сегодня связка ручная:** добытчик готовит срез → вы переносите его в книгу → аналитик считает. Бесшовной автоматики между ролями пока нет.

## Три столпа (главная рамка)

**Контекст · Модель · Коннекторы.** Контекст — кто вы и ваши термины. Модель — сам ИИ. Коннекторы — доступ к источникам. Соберите все три даже в MVP-виде — дальше можно делать почти что угодно. Не хватает одного — получаете красивое демо мимо вашего бизнеса.

## Маршрут живого демо (повторите на своей таблице)

1. **Понимание книги** — «опиши датасет: сколько строк, какие поля, диапазон».
2. **Очистка грязных колонок** — нормализовать разные написания одной категории в единый вид, отдельной чистой колонкой, не ломая исходник.
3. **Анализ текста и классификация** — по колонке с текстом (транскрипт/отзыв) проставить тему, тональность, выводы; разметить всю таблицу одним запросом.
4. **Графики** — круговая по темам, столбчатая по тональности, линейная по динамике.
5. **Финмодель** — выручка, себестоимость, валовая прибыль, маржа %, операционная прибыль по всем месяцам **живыми формулами** (меняешь вводные — пересчитывается). Режим «а что, если».
6. **Exec-дашборд** — «собери сводку и графики на отдельном листе» одним промптом.

## Стартовые промпты

**1. Опиши данные (всегда первый шаг):**
```
Посмотри на открытую книгу целиком и опиши, что это за данные.
Какие листы и столбцы, что в них, сколько строк. Где проблемы:
пропуски, дубли, разные форматы в одной колонке. Пока ничего не меняй.
```

**2. Очисти:**
```
Приведи данные в порядок: сведи разные написания одной категории к единому
виду; убери дубли строк; заполни очевидные пропуски. Покажи, что изменил,
и не трогай исходные формулы.
```

**3. Классифицируй по смыслу:**
```
Добавь колонку «Категория» и проставь её для каждой строки по смыслу текста
в колонке [название]. Набор категорий: [заказ, жалоба, вопрос, отказ, прочее].
Не уверен — ставь «прочее», не выдумывай. В конце — сводка по категориям.
```

**4. Дашборд:**
```
Собери сводку и графики по этим данным на отдельном листе.
```

## Установка (5 минут)

1. Excel — десктоп Microsoft 365 или бесплатный Excel в браузере на office.com.
2. Вкладка **Insert → Add-ins** → найти **«Claude by Anthropic»** → **Add**.
3. **Sign In** аккаунтом Claude (тариф Pro и выше). Появляется боковая панель.

**Про модель и тариф:** на старте и сложных задачах — самая мощная модель; на рутинных повторяющихся операциях — переключиться на модель попроще ради экономии. Минимум для проб — Pro; для ежедневной работы комфортнее выше.

## Честные границы

- **Песочница.** Аналитик видит только открытую книгу. Диск, CRM, почта недоступны, пока не подключишь коннектор (добытчика).
- **Большие данные.** На десятках тысяч строк медленнее и теряет детали — режь на срезы.
- **Проверяй цифры.** Финальные числа для решений сверяй сам; хороший приём — отдельный агент-критик, перепроверяющий выводы.
- **Формулы и макросы.** Проси оставлять читаемые живые формулы (иногда пишет результат «кодом»). Макрос напишет, но код в редактор Visual Basic вставляешь сам.
- **Конфиденциальность.** Данные уходят в модель. По 152-ФЗ гарантий нет — для экспериментов бери обезличенные датасеты, финансы и ПДн — через защищённый контур.
